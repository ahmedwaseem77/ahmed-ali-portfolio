# Ahmed Ali — DaVinci Resolve Video Editor & Colorist Portfolio

An Apple-inspired minimalist portfolio website for Ahmed Ali, specialized in DaVinci Resolve Studio post-production, commercial editing, high-retention short-form reels, and luxury real estate showcases.

## 📁 File Structure

```
ahmed-ali-portfolio/
├── index.html          # Homepage: Profile hero, value prop, 2-column video grid (6 Google Drive previews)
├── services.html       # Services: Packages for Reels, Real Estate, and Commercials + 5-step pipeline
├── contact.html        # Contact: Project brief inquiry form, direct WhatsApp card, email copy & FAQ
├── assets/
│   └── ahmed-ali.jpg   # Profile photograph of Ahmed Ali
└── README.md           # Project documentation and deployment instructions
```

## 🎨 Design System
- **Apple Minimalist Aesthetic:** Deep black `#000000`, crisp typography (SF Pro / Inter font stack), frosted glass navigation (`backdrop-filter: blur(24px)`), and subtle 1px border cards.
- **Micro-Interactions:** Smooth hover transitions, interactive mobile drawer, active channel badges, dynamic toast alerts, and one-click email copying.
- **Responsive:** Fluid layout optimized for mobile screens, tablets, and ultra-wide displays.
- **Embedded Videos:** 2-column grid embedding all 6 Google Drive project previews in responsive, sleek media player containers.

## 🚀 Live Preview Locally

You can preview the website immediately by opening `index.html` in your browser or running a lightweight local server:

```bash
# Option 1: Python 3
python3 -m http.server 8080

# Option 2: Node.js (npx serve)
npx serve .
```
Then visit `http://localhost:8080` in your web browser.
